# Client Communications Log

Paste all client communications here — emails, messages, meeting notes, call summaries.
This is the single source of truth for what the client said, asked for, or agreed to.

## Format

For each entry, use this template:

```
### YYYY-MM-DD | <channel> | <participants>
<!-- channel: email, slack, call, meeting, text, etc. -->
<!-- participants: who was involved -->

<paste or summarize the communication here>

**Key takeaways:**
- <decisions made>
- <requests or changes>
- <action items>
- <open questions>
```

## Usage

- Paste communications chronologically (newest at the bottom).
- Don't edit or sanitize past entries — they're a record. Add corrections as new entries.
- Tag key takeaways so they're scannable without re-reading the full message.
- When a communication changes scope or requirements, flag it: `**[SCOPE CHANGE]**`
- When a communication resolves a dispute or ambiguity, flag it: `**[DECISION]**`
